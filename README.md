# Sunflower-blog

Public asset repository for the Blogger theme **A Sunflower's Universe**.

## Navigation assets
The navigation buttons, four gold star separators, and two floral end ornaments are separate SVG files under `assets/`. Each navigation button is an independent link in the Blogger HTML gadget.

## Public asset base URL
`https://raw.githubusercontent.com/futuristicsunflower-bit/Sunflower-blog/main/assets/`

## Blogger navigation snippet
See [blogger-navigation.html](blogger-navigation.html).

The SVGs use pink enamel and metallic-gold gradients. They are hosted publicly so Blogger can load them without embedding Base64 data in the theme XML.
