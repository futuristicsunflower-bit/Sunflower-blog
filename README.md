# A Sunflower's Universe

Public design assets for the Blogger theme.

## Assets
- Header banner and welcome panel
- Metallic-gold directory ribbon
- Five separate directory cards
- Futuristic Sunflower profile medallion
- Five separate navigation buttons
- Four independent gold star separators
- Left and right floral navigation ornaments

All assets are hosted as public SVG files under `assets/`, so Blogger can load them over HTTPS without Base64 image payloads in the theme XML.

## Blogger navigation
The separate linked-button markup is in [blogger-navigation.html](blogger-navigation.html).

## Theme package
The Blogger XML is delivered separately as a downloadable file in the ChatGPT conversation. It retains the original native Blogger widgets and adds independent HTML gadgets for the illustrated sections.
